# Experimental Bubble Implementations

This directory contains experimental and prototype implementations of various bubble styles and rendering techniques.

## Contents

These files are experimental and may not be fully integrated into the main library. They serve as:
- Proof-of-concept implementations
- Testing grounds for new features
- Reference implementations for specific styles
- Cairo-based rendering experiments

## Usage

These files are not part of the main package API. If you want to use them, you can import them directly:

```python
import sys
sys.path.append('examples/experiments')
from cairo_manga_bubbles import some_function
```

## Note

These experimental files may:
- Have incomplete documentation
- Not follow the standard API conventions
- Require additional dependencies
- Be removed or refactored in future versions
