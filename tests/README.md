# Tests

This directory contains test files for the manhwa-bubbles library.

## Test Files

- `test_library.py` - Main test suite for core functionality
- `test_centered_bubbles.py` - Tests for centered bubble positioning
- `clipping_test.py` - Tests for clipping and border improvements
- `obvious_clipping_test.py` - Additional clipping tests
- `adaptive_test_800x1200.py` - Adaptive bubble sizing tests

## Running Tests

```bash
# Run all tests
python -m pytest tests/

# Run specific test file
python tests/test_library.py
```

## Test Outputs

Generated test images are saved in this directory but are excluded from git via `.gitignore`.
